# ECU Legacy-to-New URL Map

_Planning map; redirects require ECU approval before activation._

| Legacy area | New destination | Type | Notes |
|---|---|---|---|
| `https://ecu.edu.eg/` | `/` | Permanent redirect candidate | New homepage |
| `https://ecu.edu.eg/faculties/` | `/faculties` | Permanent redirect candidate | Local directory |
| Individual faculty URLs | `/faculties/[slug]` | Permanent redirect candidate | Confirm slug mapping per faculty |
| `https://ecu.edu.eg/about-ecu/admission/` | `/admissions` | Permanent redirect candidate for information | Preserve live application integration separately |
| `https://ecu.edu.eg/research-plan/` | `/research` | Permanent redirect candidate | Local research objectives migrated |
| `https://ecu.edu.eg/news/` | `/news-events` | Permanent redirect candidate | Local dated articles still need migration |
| Public contact/location pages | `/contact` | Permanent redirect candidate | Phone/email/service records need confirmation |
| LMS, portal, email and payment systems | Authorized external service URL | External integration | Do not redirect or replace without ECU approval |

No redirects are enabled by this project. The map must be reviewed against server logs, indexed URLs, localized paths, documents and approved launch requirements before implementation.
