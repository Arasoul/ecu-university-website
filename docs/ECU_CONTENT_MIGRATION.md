## Migration rules

- Local routes are the primary destination for public informational content.
- Official admissions remains an authorized external transactional integration until ECU supplies a replacement or integration contract.
- Source URLs remain in data for traceability, not as substitutes for local informational pages.
- Every article, event, programme and media record requires source URL, original language, date, verification date, status and rights metadata before publication.
